# Gogame

브라우저에서 바로 즐기는 바둑 게임입니다.

## 바로 플레이

- https://beerandnacho.github.io/go/

공개 플레이 페이지는 `Gogame` 저장소의 고정 커밋 소스를 jsDelivr로 읽습니다. 게임 로직의 원본은 이 저장소 하나만 유지합니다.

## 현재 구현

- 9×9 / 13×13 / 19×19 바둑판
- 사람 vs AI / 2인 대국
- 흑 / 백 선택, 백 선택 시 AI 선공
- 따냄, 자살수 금지, 단순 패(ko), 패스, 무르기
- 두 번 연속 패스 시 자동 계가
- 중국식 면적 계가(돌 + 둘러싼 빈집, 백 덤 6.5)
- 초보자 도우미: 단수 표시, 착수 미리보기, 추천수
- AI 난이도: 입문 / 보통 / 도전
- 자동 저장 및 지난 대국 이어하기
- 착수/따냄 소리와 모바일 진동
- 모바일 터치 대응
- 키보드 단축키: `U` 무르기, `H` 추천수, `P` 패스, `S` 계가, `N` 새 대국
- Node 내장 테스트 기반 규칙 엔진 검증

## 개발 구조

```text
src/
  go-engine.js   # 규칙/착수/따냄/패/계가
  ai.js          # 로컬 휴리스틱 AI
  app.js         # 화면/게임 흐름
  styles.css     # UI

tests/
  go-engine.test.js
```

## 로컬 실행

정적 웹앱이라 별도 빌드가 필요 없습니다.

```bash
python3 -m http.server 8080
```

브라우저에서 `http://localhost:8080`을 엽니다.

테스트:

```bash
npm test
```
