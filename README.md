# Gogame

브라우저에서 바로 즐기는 **바둑 + 오목** 게임입니다.

## 바로 플레이

- https://beerandnacho.github.io/go/

공개 플레이 페이지는 `Gogame` 저장소의 고정 커밋 소스를 jsDelivr로 읽습니다. 게임 로직의 원본은 이 저장소 하나만 유지합니다.

## 공통 기능

- 바둑 / 오목 즉시 전환
- 사람 vs AI / 2인 대국
- 흑 / 백 선택, 백 선택 시 AI 선공
- AI 난이도: 입문 / 보통 / 도전 / **극강**
- 추천수
- 무르기
- 자동 저장 및 지난 대국 이어하기
- 착수 소리와 모바일 진동
- 모바일 터치 대응
- AI는 브라우저 내부 휴리스틱/탐색 로직으로만 동작 — 외부 AI API 비용 없음

## 극강 AI

### 바둑

- 상위 후보수 범위 확대
- 상대의 최선 응수 비교
- 9×9 / 13×13에서는 상대 응수 뒤 내 재응수까지 추가 평가
- 랜덤 선택을 제거하고 최악의 상대 응수에 가장 덜 흔들리는 수를 선택
- 19×19에서는 브라우저 성능을 고려해 탐색 폭을 제한

### 오목

- 즉시 승리수 최우선
- 상대 즉시 5목 완전 방어
- 다음 차례의 강제승리 포크 탐색
- 상대 최선 응수 뒤 내 후속 공격까지 비교
- 열린 3/4와 연속선 위협을 크게 가중
- 금수룰에서는 흑의 금수 후보를 자동 제외

> `극강`은 무료 브라우저 로컬 AI 범위에서 가장 깊게 읽는 모드입니다. 바둑의 KataGo 같은 신경망 엔진과 동일한 수준은 아닙니다.

## 바둑

- 9×9 / 13×13 / 19×19
- 따냄
- 자살수 금지
- 단순 패(ko)
- 패스
- 두 번 연속 패스 시 자동 종료
- 중국식 면적 계가(돌 + 둘러싼 빈집, 백 덤 6.5)
- 단수 표시

## 오목

- 15×15
- 자유룰: 흑/백 모두 5목 이상 승리
- 일반 금수룰: 흑의 3-3 / 4-4 / 장목 금지, 백은 제한 없음
- 가로 / 세로 / 대각선 승리 판정
- AI 즉시 승리수 우선
- 상대의 즉시 5목 위협 방어
- 주변 후보수 중심 탐색으로 모바일 성능 최적화
- 승리 결과 팝업

> 오목의 `일반 금수룰`은 즐기기 위한 일반적인 3-3/4-4/장목 제한 모드입니다. 국제 렌주 대회의 복잡한 오프닝 규칙 전체를 구현한 모드는 아닙니다.

## 개발 구조

```text
src/
  go-engine.js      # 바둑 규칙/따냄/패/계가
  ai.js             # 바둑 로컬 AI
  omok-engine.js    # 오목 승리/금수/무르기
  omok-ai.js        # 오목 로컬 AI
  app.js            # 바둑/오목 통합 화면과 게임 흐름
  styles.css        # 기본 UI
  status.css        # 상태 칩/게임 전환/오목 UI

tests/
  go-engine.test.js
  omok-engine.test.js
```

## 로컬 실행

정적 웹앱이라 별도 빌드가 필요 없습니다.

```bash
python3 -m http.server 8080
```

브라우저에서 `http://localhost:8080`을 엽니다.

테스트:

```bash
npm test
```

CI에서는 게임 스크립트 문법 검사와 규칙 테스트를 함께 실행합니다.
