# Gogame

브라우저에서 바로 즐기는 바둑 게임입니다.

## 첫 버전 목표

- 9×9 / 13×13 / 19×19 바둑판
- 사람 vs AI / 2인 대국
- 따냄, 자살수 금지, 단순 패(ko), 패스, 무르기
- 두 번 연속 패스 시 계가
- 중국식 면적 계가(돌 + 둘러싼 빈집, 백 덤 6.5)
- 초보자용 합법수 표시, 단수 표시, 추천수
- AI 난이도: 입문 / 보통 / 도전
- 모바일 터치 대응
- 게임 상태 저장 및 재시작

## 개발 구조

```text
src/
  go-engine.js   # 규칙/착수/따냄/패/계가
  ai.js          # 로컬 휴리스틱 AI
  app.js         # 화면/게임 흐름
  styles.css     # UI

tests/
  go-engine.test.js
```

## 실행

정적 웹앱이라 별도 빌드가 필요 없습니다.

```bash
python3 -m http.server 8080
```

브라우저에서 `http://localhost:8080`을 엽니다.

테스트:

```bash
npm test
```

## 규칙 메모

첫 버전은 재미있게 빠르게 즐기기 위한 캐주얼 바둑을 목표로 합니다. 계가는 **중국식 면적 계가**를 사용하며, 죽은 돌을 사용자가 따로 지정하는 심판 단계는 아직 없습니다. 실제 대국 서버/KataGo/SGF/정밀 계가 기능은 다음 단계에서 확장합니다.
